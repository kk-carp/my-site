# 林安的个人网站原型

无需安装依赖或构建，直接用浏览器打开 `index.html` 即可。也可在本目录运行 `python -m http.server 4173 --bind 127.0.0.1`，访问 http://127.0.0.1:4173。

- `index.html`：首页，自我介绍、兴趣、联系方式图标、最近作品和文章。
- `projects.html`：作品网格，可展开项目说明。
- `blog.html`：文章列表，按示例日期倒序。
- `article.html`、`article-ai.html`、`article-travel.html`：三篇示例文章。
- `styles.css`：布局、响应式、亮暗色 CSS 变量。
- `app.js`：主题切换、偏好保存、跟随系统主题及滚动淡入。

亮色主色选择陶土橙 `#B85C38`。配色以需求指定值为基础；暗色区块、分割线等通过指定颜色混合或透明度生成。标题用系统衬线字体，正文用系统无衬线字体；没有外部字体、图片或框架依赖。

作品、文章及日期为明确标注的展示示例，后续替换为真实内容。邮箱和 GitHub 仅为图标，没有链接。页面为本地静态原型，尚未发布。

验证：页面 HTTP 访问、内部链接完整性、JavaScript 语法、桌面与手机布局、主题切换与文章跳转。
