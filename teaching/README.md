# 项目二教学包

与上层课程第3—6章配合使用。工程内 spec.md 为可独立分发的规则，tasks.md 为进度；每章90分钟，概念27分钟、带练63分钟。实际试教尚未进行，不把开发耗时当作教学耗时。

## 发放与阶段

教师在完整工程运行 `npm run teaching:pack`，在 preview/ 下生成带时间戳的新目录及 manifest，不覆盖旧包。可将各目录单独压缩分发；它们包含源码和锁文件，不含依赖、Git历史、环境变量或收藏。学生进入对应目录 npm ci 后启动。

- 03-complete：调查、规格、任务及原主页，无 /learn。
- 04-starter：工具页骨架，upsert 待实现、filterResources 待补交集；可启动，练习功能与对应测试预期未通过。
- 04-complete：内存增删改与筛选，刷新为空，无存储/CSV/星标界面。
- 05-starter：第4章核心已提供，存储写入与CSV预览留作练习；失败提示指导补齐。
- 05-complete：v1 保存及四列CSV，无星标界面。
- 06-starter：延续第5章 v1，先更新规格，切换页面 stage=6，再完成 CR-01。
- 06-complete：完整 v2 成品。

这些是从当前源码生成的阶段能力版本，不是假装存在的历史提交。共享模块含教师已提供的适配器和兼容代码；06-starter 的兼容代码可供阅读，不等于学生已完成独立实现。课堂要保留真实学生 Diff 与验证记录。正式阶段版本通过后再由教师自行提交/打标签。

## 第3章：调查→范围→规格

3.1（9+20分钟）：打开 research.md 与固定 vendor 源码，核对许可、parse/unparse 和公式保护入口；运行带逗号标题的最小样例。Linkding 只用于产品流程参考，不部署其系统。

3.2（8+18分钟）：定位公共导航、learn.astro、客户端入口与 rules/storage/csv 职责；说明浏览器收藏与公共博客的区别。

3.3（10+25分钟）：核对 spec/tasks，先手算 mixed.csv 1新1重1错，再写输入/操作/预期。保存规格版本，不直接发最终成品替代跟做。

## 第4章：资源操作→筛选边界→Skill

4.1（9+25分钟）：从04-starter补 upsert，统一校验、自己编辑排重、顺序和取消行为；只用内存。

4.2（10+20分钟）：补 filterResources；用三条固定示例查交集，检查 HTML外观文本、非法协议和 URL 尾斜杠去重。

4.3（8+18分钟）：修改 `.agents/skills/resource-check/SKILL.md` 的章节检查说明。课程以 Codex 为当前示例环境；在支持项目 `.agents/skills` 发现的会话中重新打开工程，确认技能列表出现 resource-check，再明确调用 `$resource-check`。若未出现，按现场工具规范配置，不把普通聊天当真实 Skill 调用。保存工具版本、发现入口、调用记录和一项人工复核。

Plugin示范候选为当前教学环境已有的 computer-use 插件，需教师核对实际安装版本、来源、屏幕读取与操作权限，以及插件管理页停用方式。仓库不安装扩展、不保证学生具备该插件；课堂前实际演示仍待补。无插件可人工复核，插件演示记未执行。

## 第5章：保存→CSV→Harness

5.1（9+23分钟）：从05-starter补存储写入。先候选校验再写成功提交，测试恢复及坏数据；用 faults.mjs 注入失败，不破坏真实收藏。

5.2（9+22分钟）：补预览的逐行校验/去重，先预览与取消，再接确认保存、下载和全量往返。mixed.csv 预览1/1/1，确认4条，取消/保存失败3条。

5.3（9+18分钟）：运行 npm run check:resources，记录首个失败、最小Diff与复测。故障F01设 readFailure=true；F02设 writeFailure=true；F03传 raw='{'；F04传未知版本。恢复时将故障开关复原或重建内存适配器，不清理真实localStorage。对照 tests 的独立预期修复错误实现，不能改测试求通过。两轮无效修复整理交接。

## 第6章：变更→PR回归→发布

6.1（9+22分钟）：从06-starter保留 v1 JSON/旧CSV，真实创建 CR-01 分支；先改规格，再启用 v2 星标；核对迁移失败保留原始值。

6.2（10+23分钟）：按检查Skill执行 A01—A06 和 CR-01，分别记录 check:resources/check/build/verify。PR建议标题：“增加学习资源管理器与星标兼容”；正文写工具用途、v1/旧CSV兼容、实际验证及未执行项。未真实提交、创建PR或评审时保留待办。

6.3（8+18分钟）：按原Workers配置发布，记录真实提交和云端日志；上线后访问 /learn/，从主页导航进入，检查手机操作、404及另一浏览器首次空白；导入非敏感CSV再刷新。发布前后来源不同，通过CSV迁移。详见 release-checklist.md。

## 练习验收

Node规则测试不替代实际浏览器；JSDOM事件测试不证明布局与原生下载已通过。各章记录输入、操作、预期、实际、证据、未完成项；可以复用课程实践记录模板。骨架预期失败、完整版本回归成功、试教耗时分别记录。
